# Assets externos

Este diretório está preparado para os assets oficiais fornecidos pelo proprietário do portfólio.

- `mirame-cover.webp`: exporte a capa oficial em proporção 16:9. Ao adicioná-la, substitua o bloco `.mirame-art` por uma `img` com `width`, `height`, `loading="lazy"` e `decoding="async"`.
- `cursor.png`: imagem oficial do cursor. O cursor customizado só deve ser ativado após o carregamento bem-sucedido deste arquivo e apenas em dispositivos com ponteiro preciso.

Os arquivos não foram fabricados nesta alteração: nenhum screenshot ou cursor oficial estava presente nos arquivos recebidos.
